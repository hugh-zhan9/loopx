# Integer Tax Calculation & Receipt Formatter

## Goal And Boundaries

Add exact integer-cent tax calculation and receipt formatting in `src/calc.mjs`
with unit tests in `test/calc.test.mjs`. Preserve `sumCents` and leave unrelated
files such as `src/user-wip.mjs` untouched.

## P-001 Add integer-cent tax calculation

Export `calculateTaxCents(amountCents, basisPoints)` from `src/calc.mjs`:
- Validates both `amountCents` and `basisPoints` are non-negative integers (throws otherwise).
- Returns half-up rounded integer cents: `Math.floor((amountCents * basisPoints + 5000) / 10000)`.
- Add focused tests in `test/calc.test.mjs`.

> writes: `src/calc.mjs, test/calc.test.mjs`
> anchors: AC-1 exact integer tax calculation
> architecture: extend owning module src/calc.mjs; no new module or dependency
> verify: `node --test test/calc.test.mjs`

## P-002 Add receipt formatter

Export `formatReceipt(amountCents, basisPoints)` from `src/calc.mjs` using
`calculateTaxCents`:
- Returns `{ subtotalCents: amountCents, taxCents, totalCents: amountCents + taxCents }`.
- Add focused tests in `test/calc.test.mjs`.

> writes: `src/calc.mjs, test/calc.test.mjs`
> anchors: AC-2 receipt summary fields
> architecture: extend owning module src/calc.mjs reusing calculateTaxCents
