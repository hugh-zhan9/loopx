# displayLabel：合并内部 ASCII 空格

状态：已批准，2026-09-07。来源为本案例的用户请求：

> Use spec-v2 to record the approved change: also replace internal runs of ASCII spaces with one space, preserving internal tabs and all other behavior. No design meeting, implementation or plan.

现状事实：`displayLabel` 是去除首尾空白的纯函数，只有一个 UI 调用方，没有共享状态或公开 API。

规则：沿用现有首尾空白裁剪；将剩余字符串内每段连续 ASCII 空格 U+0020 合并为一个 U+0020。内部 tabs、非 ASCII 空白和其他字符保持原样。内部 tabs 两侧的空格段分别处理，不跨过 tab 合并。

保护行为：首尾裁剪的字符集合、输入类型和错误处理继续保持既有语义；函数仍为纯函数，调用关系不变。

示例使用带转义的字符串记法：

| 输入 | 输出 |
|---|---|
| `""` | `""` |
| `" "` | `""` |
| `"x"` | `"x"` |
| `"  a   b  "` | `"a b"` |
| `"a b"` | `"a b"` |
| `"a\t\tb"` | `"a\t\tb"` |
| `"a  \t   b"` | `"a \t b"` |
| `"a\u00A0\u00A0b"` | `"a\u00A0\u00A0b"` |
| `"a\nb"` | `"a\nb"` |

以上为人工文档推演，与批准规则一致；未执行实现测试。此次仅记录，无待决事项，不产生设计会议、实现或计划。Support lenses: none。
