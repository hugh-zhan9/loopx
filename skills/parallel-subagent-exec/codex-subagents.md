# Codex Adapter

Discover native create and wait/observe tools, including deferred tool
discovery, before declaring capability unavailable. Use `spawn_agent` for each
reserved stage and `wait_agent` or an equivalent observer for recorded agents.
Set the model explicitly and set cwd to the owned task, retry, child, or root
worktree named by controller state.

Independent reservations may be dispatched together up to the effective
global budget. Do not spawn a dependent stage early. Release completed workers
when supported; an empty wait result is not failure.

Every implementer, task reviewer, fixer, reconciliation worker, plan reviewer,
and final reviewer receives:

`You are a leaf worker. Do not spawn, delegate to, or wait for other agents.`

The worker receives only its brief, report path, review package or conflict
evidence, owned cwd, and required context. The controller captures the native
agent id and terminal result and alone advances state or Git.
