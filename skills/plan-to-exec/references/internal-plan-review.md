# Internal Plan Review Contract

Run `plan-reviewer` after the draft is complete and before saving or handing it
off. The reviewer is a leaf worker under `../../shared/agent-topology.md`.

- Inputs: approved source, draft plan, and only selected repo specs or memory.
- Critical or Important findings block save and execution handoff.
- Missing source decisions return to `clarify` or `spec`; planning does not
  invent them.
- Same-context review is allowed only when independent review is unavailable
  and records degraded independence.

The final plan records review mode, reviewer independence, unresolved findings,
review evidence, recheck evidence, and residual risk.
