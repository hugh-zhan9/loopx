# Surface Change Planning Contract

Use this contract when work removes, replaces, narrows, migrates, or changes
compatibility for public or runtime surfaces.

Inventory current commands, APIs, schemas, events, config, package contents,
templates, hooks, permissions, docs, and tests. Every retained item needs a
current-source caller; historical plans, designs, and release notes do not count.

Plans include exact caller-proof searches and negative assertions. Strict
current product paths must be clean after removal. Rewritten tests must prove
the removed behavior cannot silently return.
