# loopx 0.2.2

## Summary

`0.2.2` adds final whole-feature review to the v1 skill suite and tightens finish-time learning extraction.

## Changed

- Added `final-review` for post-implementation, pre-finish integration and runtime-risk review.
- Updated `subagent-exec` to hand off to `final-review` after all planned tasks complete.
- Clarified that task/checkpoint `review` and its matching `fix-review` run inside execution, while final-review feedback is handled before `finish`.
- Updated `finish` learning extraction to prioritize implementation-proven behavior, contracts, invariants, user decisions, and reusable review findings.
- Documented `finish` as the terminal completion step, with reruns reserved for keep-as-is, PR iteration, interruption before choice execution, or new changes after review feedback.
- Bundled `final-review` in npm and plugin skill installs with governance coverage.
