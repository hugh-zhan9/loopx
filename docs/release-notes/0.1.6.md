# loopx 0.1.6

`0.1.6` improves Codex-facing workflow continuity and plan review ergonomics.

## Added

- Added automatic HTML reading-view generation after successful `plan` runs, including the workflow plan view and workspace index.
- Added archive-time consumption of pending approved `review -> done` transitions so `$archive <slug>` can complete and archive in one Codex skill invocation.
- Added compatibility handling for review states that record approved completion as `go` routed to `done`.

## Changed

- Updated clarify, plan, build, and review skill handoff guidance to prefer artifact-pinned commands only when they clarify the next action.
- Updated plan documentation and skill output guidance to surface the generated HTML plan review entrypoint.
- Updated archive documentation so agents do not ask users to run a separate terminal approval command when review has already approved the workflow for `done`.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.6`.
