# loopx 0.8.1

- Redesign the `plan2exec` plan document into a readable hybrid format: a
  narrative body for human approval plus YAML frontmatter carrying the slice
  graph (`P-*` ids, explicit `depends`, per-slice `status`).
- Replace per-slice field lists with prose acceptance closed by a compact
  `writes` / `anchors` / `verify` / `review` meta block.
- Require every slice to declare `depends` explicitly; an empty list asserts
  independence so parallel safety is never inferred from omission.
- Align `plan-reviewer` with the new plan shape and drop the stale
  structural-profile output requirement.
