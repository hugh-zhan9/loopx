# loopx 0.4.0

`0.4.0` is a larger workflow-contract release for the skill-first loopx
harness. It tightens the main feature workflow from clarification through
review and finish, adds multi-plan package execution, and makes review output
responsible for minimizing unnecessary implementation complexity.

## Changes

- Added clarify intake packages and templates so clarification handoff keeps
  requirements, open questions, and test cases together.
- Added design anchors and task anchors across `spec`, `plan-to-exec`, and
  `review` so plans and reviews preserve approved design decisions instead of
  checking code in isolation.
- Added `plan-reviewer` as a bundled support skill and required internal plan
  review before implementation handoff.
- Added execution range state, final-review report contracts, and finish gates
  so review and completion can cite concrete implemented ranges.
- Added multi-plan package mode for `exec` and `subagent-exec`, including
  sequential child-plan orchestration and spec-level final-review finish gates.
- Updated `lancet`, `review`, and `fix-review` contracts to flag unanchored
  fallback, degradation, retry, shim, and silent-recovery logic unless it is
  explicitly required by the user, requirements, approved design, plan, or
  issue contract.
- Constrained the package docs surface to current product documentation and
  removed local article/deepsearch artifacts from the repository.
- Bumped the npm package and Codex plugin manifest versions to `0.4.0`.
