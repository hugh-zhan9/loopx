# loopx 0.1.8

- Added requirement traceability to the generated workflow plan HTML view.

- Added Markdown table, ordered-list, inline-code, and bold rendering support for generated HTML views.

## Changed

- Updated generated requirement traceability artifact headings and fixed labels to Chinese.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.8`.
