# loopx 0.3.6

`0.3.6` hardens `subagent-exec` capability checks across agent runtimes.

## Changes

- Added platform-specific subagent references for Codex, Claude Code, and
  Cursor.
- Added a platform-neutral subagent capability preflight before falling back to
  `exec`.
- Documented Codex deferred-loaded multi-agent tool discovery so
  `subagent-exec` does not prematurely downgrade when `spawn_agent`,
  `wait_agent`, and `close_agent` are available through tool discovery.
- Clarified Cursor Cloud Agent compatibility boundaries for task-by-task
  controller review.
- Updated governance coverage for the new platform references.
