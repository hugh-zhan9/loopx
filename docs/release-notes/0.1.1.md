# LoopX 0.1.1

## Summary

`0.1.1` is the follow-up release that fixes the invalid skill packaging in `0.1.0` and aligns the public skill names with the chosen generic naming surface:

- `clarify`
- `plan`
- `build`
- `review`
- `autopilot`

## Fixes

### Valid SKILL.md packaging

All published skill files now include required YAML frontmatter, so Codex no longer skips them as invalid skills.

### Generic skill names

The public skill names no longer use the `loopx-` prefix.

### Shared dual-distribution convergence

npm and plugin installs continue to converge on:

- one `installationIdentity=loopx`
- one visible skill set
- merged provenance across npm/plugin shells

## Install

```bash
npm install -g @ai-content-space/loopx
```

## Verification Snapshot

Validated before release:

- root install/discovery bootstrap
- plugin shell tests

- runtime smoke for `loopx init`, `loopx status`, `loopx doctor`
