# loopx 0.9.0

- Add `exec` as an optional bundled skill for executing one ready `plan2exec`
  document through host-native leaf subagents. Independent slices may run in
  parallel while the top-level model owns scope review, sequential integration,
  conflict handling, and final verification. Users may select the subagent
  model, reasoning effort, and worker limit. Upgrades preserve legacy or
  same-name `exec` installs when ownership cannot be proven from the template
  baseline instead of overwriting them.
- Update `generate-api-docs` to target self-contained OpenAPI 3.1 contracts,
  trace client-visible gateway and serializer behavior, document operational
  limits and presentation enums, and validate nullable schemas and examples
  more completely.
