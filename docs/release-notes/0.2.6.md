# loopx 0.2.6

## Summary

`0.2.6` tightens blocked clarify workflow guidance in the CLI status and next-step surfaces.

## Changed

- Fixed human `loopx status` blocked detection for early clarify stages by surfacing readiness blockers.
- Removed the duplicate fallback `next` line from human `loopx status` output.
- Made `loopx next <slug>` command-first for early clarify stages by surfacing both `$clarify <slug>` and `loopx clarify <slug>`.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.6`.
