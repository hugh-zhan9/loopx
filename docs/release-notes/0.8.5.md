# loopx 0.8.5

- Add `generate-api-docs` as a bundled support skill for documenting existing
  HTTP APIs from verified repository evidence.
- Generate synchronized field-level Markdown documentation and a self-contained
  OpenAPI YAML contract importable by Apifox, including nested request fields,
  response fields, descriptions, constraints, and examples.
- Ship a deterministic validator for Markdown/OpenAPI operation parity, local
  references, path parameters, field descriptions, and required response
  documentation sections.
- Report the validator's Ruby runtime prerequisite through `loopx doctor`.
- Keep API documentation generation inside the docs-first boundary: it records
  current contracts without designing new APIs, changing implementation, or
  creating workflow state.
