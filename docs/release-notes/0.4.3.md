# loopx 0.4.3

`0.4.3` is a patch release for clarify intake artifact simplification.

## Changes

- Made `requirements.md` the canonical clarify intake contract and kept
  `clarification.md` as supporting process and resume evidence.
- Removed the standalone clarify `test-cases.md` artifact and package template.
- Removed the old standalone test-cases surface from CLI, hooks, HTML views,
  workflow state, docs, and skill contracts.
- Added governance checks for empty skill sections and removed test-cases
  surface regressions.
- Added Chinese final-review reviewer output guidance.
- Bumped the npm package and Codex plugin manifest versions to `0.4.3`.
