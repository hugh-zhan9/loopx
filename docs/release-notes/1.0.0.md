# 1.0.0

Major release slimming the loopx skill bundle around dual-channel invocation,
positive procedural craft (absorbing patterns from `mattpocock/skills`),
deterministic guardrail scripts, and real end-to-end A/B evaluation.

## Breaking changes & bundle slimming

- Reduce the bundled skill set from 23 to **15** high-signal skills and cut
  total `skills/` text by ~69% (from ~20.3k lines to ~6.3k lines).
- **Dual-channel invocation split** (enforced by `scripts/verify-skills.mjs`):
  - **3 Model-invoked disciplines** remain always-discoverable (`debug`, `tdd`,
    `go-kratos`), cutting always-on description context load by >80%.
  - **12 User-invoked skills** (`task-split`, `clarify`, `spec`, `plan2exec`,
    `exec`, `code-review`, `refactor-plan`, `release-readiness`,
    `generate-api-docs`, `humanize-doc`, `codebase-spec`, and the new
    human-facing router `ask-loopx`) carry `disable-model-invocation: true`
    (Claude Code) and `policy.allow_implicit_invocation: false` in
    `agents/openai.yaml` (Codex) for zero always-on context cost.
- **Retire 11 bloated, redundant, or textbook skills** (`lancet`,
  `api-designer`, `sql-style`, `cli-developer`, `architecture-designer`,
  `requirement-analyzer`, `using-git-worktrees`, `prompt-lint`,
  `maintain-project-docs`, `go-style`, `kratos`) and 4 redundant shared
  contracts (`architecture-conformance.md`, `completion-check.md`,
  `evidence-contract.md`, `task-scope.md`). Pristine loopx-owned copies are
  cleaned up safely on upgrade while preserving user-modified files.
- Merge the non-obvious Go and Go-Kratos redlines (exact numeric precision,
  domain subpackages, generated-file boundaries, no DB locks, MySQL/Ent
  comments) into one lean `go-kratos` skill.
- Distill high-signal rules from retired skills into their consuming workflows:
  `spec/references/caller-driven-api.md` (caller-driven DTOs, no DB snapshot
  pass-through or JSON-in-string) and `clarify/references/ambiguity-table.md`
  (Chinese PRD vague-term triggers).

## Working agreement & core skill rewrites

- Slim `templates/working-agreement.md` from 161 lines to 42 lines, removing
  project-specific patch examples, always-on mutation checks (kept scoped to
  explicit `tdd`), and automatic review-subagent dispatch on routine diffs or
  documentation drafts.
- Rewrite core skills with concrete steps, leading words, and binary completion
  criteria:
  - `debug` 0.6.0: tight red-capable feedback loop before hypothesizing,
    minimized reproduction, 3–5 falsifiable hypotheses, `[DEBUG-<id>]` cleanup.
  - `tdd` 0.4.0: pre-agreed public seams, vertical tracer-bullet slices, and
    explicit testing anti-patterns.
  - `code-review` 0.2.0 (new, user-invoked): independent two-axis diff review
    (Standards vs Spec) with Fowler smell baseline.
  - `clarify` 0.7.0: design-tree frontier rounds with recommended answers and
    self-discovered repository facts.
  - `spec` 0.7.0: deep-module reuse and test seams up front while keeping `D-*`
    anchors and overview/detail roles.
  - `plan2exec` 0.9.1 & `exec` 1.3.0: vertical tracer-bullet slices, safe
    expand-migrate sequencing (contract/removal only when explicitly
    authorized), frontier dispatch with sparse context pointers, and fail-closed
    admission.

## Deterministic scripts & real A/B evaluation

- Add `skills/plan2exec/scripts/validate-plan.mjs` to machine-check
  `loopx-plan/v1` frontmatter, DAG acyclicity, required slice metadata, and
  undeclared parallel `writes` overlaps.
- Add `skills/code-review/scripts/check-guardrails.mjs` to scan added diff
  lines for prohibited DB locks (`FOR UPDATE` / `LOCK TABLES`), floating-point
  financial/quantity types, and leftover `[DEBUG-...]` tags.
- Add `evals/skill-ab/` (`npm run eval:skill-ab`): 16 real Git-fixture A/B
  tasks covering `debug`, `spec`, `plan2exec`, `clarify`, and `exec` (including
  two-stage blind downstream implementation and bare-failing pressure/policy
  traps) across `bare`, `slim-agents`, `loopx-old`, and `loopx-new`.
- Connect real Codex JSONL trace extraction
  (`evals/benchmark/extract-codex-boundaries.mjs`) into
  `evals/benchmark/score-boundaries.mjs --codex-jsonl`.

## Verification

- `npm test`: 208/208 passing (including `verify-skills.mjs` dual-host
  invocation checks, 16-task A/B discrimination & 64/64 dry-run, guardrail and
  plan-validator unit tests, and real Codex JSONL boundary scoring).
- Exploratory `n = 1` live Codex (`gpt-6.2-sol @ high`) A/B pilots across 10
  high-signal tasks (`debug`, `spec`, `plan2exec`, `clarify`, `exec`) guided
  the token and regression fixes in this release; repeated `n >= 5` live runs
  remain required for statistical claims.

The npm package and Codex plugin both use version `1.0.0`. Skill
`metadata.version` values remain independent of the package version.
