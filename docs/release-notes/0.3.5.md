# loopx 0.3.5

`0.3.5` removes the generated Codex plugin skill mirror and keeps the package
root `skills/` tree as the single canonical bundled skill source.

## Changes

- Removed `plugins/loopx/skills/` and the `sync-plugin-skills` maintenance
  script.
- Updated plugin installation to materialize skills from package-root
  `skills/` while preserving plugin provenance.
- Updated governance, package checks, and plugin install tests to enforce the
  no-mirror contract.
- Documented the canonical skill source in maintainer docs, CLI docs,
  installation specs, and the skill resolver.
- Included recent skill workflow updates for issue/fix, spec, refactor-plan,
  review, final-review, and using git worktrees.
