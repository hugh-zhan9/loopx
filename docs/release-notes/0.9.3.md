# 0.9.3

- Require humanize-doc to check recorded documentation conventions in the
  repository and project memory before rewriting. A project ruling on document
  shape — current-state only, no change log, audience layering — outranks the
  shape of the source.
- Treat a term that appears only in the draft as an invented label rather than
  team vocabulary, and replace it with plain wording. Require every abbreviation,
  symbol, and date code the document relies on to be defined at first use or in
  one short table.
- Add a reader-side delivery check for undefined abbreviations, document-only
  terms, and newly introduced headings or glosses that read worse than what they
  replaced. Re-run both checks after any later structural pass, which can strip
  the definition of a term whose uses remain.
- Bump the npm package and Codex plugin to 0.9.3 for local installation.
