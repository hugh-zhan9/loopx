# loopx 0.5.2

`0.5.2` reduces user-visible polling noise in `parallel-subagent-exec` while
preserving strict worker lifecycle and isolation checks.

## Changes

- Added compact wait output for Codex and Cursor Agent CLI workers.
- Replaced repeated 30-second observation commands with long-lived wait
  sessions that controllers must reuse.
- Prevented normal progress observation from tailing event, heartbeat, stderr,
  transcript, output, or subagent lifecycle files.
- Limited progress commentary to state changes, terminal events, and bounded
  five-minute heartbeats.
- Reduced long-running Codex and Cursor filesystem observation frequency to at
  most once per second.
- Applied the same native agent-handle observation discipline to Cursor App and
  Claude Code adapters.
- Bumped the npm package and Codex plugin manifest versions to `0.5.2`.
