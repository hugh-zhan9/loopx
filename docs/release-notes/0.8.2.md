# loopx 0.8.2

- Add the `humanize-doc` bundled support skill: rewrite discipline for
  AI-generated or AI-assisted documents of any type.
- Deletion rules strip what AI drafts get wrong: invented jargon (domain
  terms stay), hedged decision wording, fabricated claims (removed via an
  explicit deletion ledger), and self-defense narration.
- Positive-construction rules protect what deletion alone destroys: a
  narrative spine on the first screen, orientation sentences that state the
  rule rather than a metaphor for it, worked examples next to every formula,
  tables that hold facts instead of compressed branching, and complete
  sentences outside tables.
- Includes an engineering-design addendum and real before/after cases in
  `references/examples.md`, distilled from a production design-doc rewrite.
- Boundary: `humanize-doc` rewrites; `doc-readability` keeps the
  assessment-first evaluation role.
