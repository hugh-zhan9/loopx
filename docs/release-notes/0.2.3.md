# loopx 0.2.3

## Summary

`0.2.3` separates skill handoffs from CLI handoffs and removes legacy owned-skill pruning from the installer.

## Changed

- Plan completion now recommends `$subagent-exec` as the next skill while exposing `loopx build` as the separate CLI handoff.
- Review rework paths now use `loopx build --from-review` instead of the removed `$build` skill handoff.
- CLI status and workflow hooks now report `next skill` and `next cli` separately when both surfaces apply.
- Renamed the subagent execution surface from `Subagent-Driven` to `Subagent Exec` across bundled and plugin skill metadata.
- Removed automatic cleanup for old loopx-owned legacy skill registry rows during install.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.3`.
