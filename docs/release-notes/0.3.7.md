# loopx 0.3.7

`0.3.7` adds `lancet`, a Codex-only support lens for implementation and review
minimization.

## Changes

- Added the bundled `lancet` support skill for over-engineering checks, repo
  reuse, stdlib/native alternatives, and smallest-correct-diff discipline.
- Added Codex hook advisory output that injects stage-aware `lancet` guidance
  for implementation and review skills, with silent degradation on missing or
  invalid local state.
- Added `loopx lancet on`, `loopx lancet off`, and `loopx lancet status` with
  JSON output support and user state under `~/.loopx/lancet/`.
- Added `LOOPX_LANCET` process-level control for enabling or disabling automatic
  guidance without rewriting local state.
- Threaded `lancet` through implementation, subagent handoff, review,
  final-review, and issue-fix contracts without changing planning-stage
  freedom.
- Added human-reviewable final-review report artifacts under
  `.loopx/final-review/<timestamp>-<slug>.md`, with finish now checking the
  saved report before completion.
- Added localized final-review report templates and moved the concrete English
  and Chinese templates into `skills/final-review/references/`.
- Updated `spec`, `clarify`, and `plan-to-exec` handoff contracts so new design
  outputs use dated design package directories such as
  `docs/loopx/design/YYYY-MM-DD-<kebab-slug>/需求设计文档.md`.
- Updated README, CLI, skills, installation, and governance docs for the new
  release surface.
