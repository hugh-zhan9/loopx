# loopx 0.2.0

`0.2.0` refocuses loopx as a skill-first suite for agentic coding assistants.

## Changed

- Replaced the legacy bundled workflow skills with the v1 skill suite: `clarify`, `spec`, `plan`, `subagent-exec`, `exec`, `review`, `fix-review`, `finish`, `refactor-plan`, `tdd`, `debug`, `verify`, `go-style`, and `kratos`.
- Made `spec` a conditional design gate; `clarify` can hand off directly to `plan` when no design artifact is needed.
- Aligned `plan`, `review`, and `fix-review` with the corresponding Superpowers planning and code-review workflows.
- Added Codex and Claude install target support, including a non-blocking Claude prompt hook.
- Pruned loopx-owned legacy skills during installation while preserving foreign same-name skills.
- Bumped package, plugin, and bundled skill metadata versions to `0.2.0`.
