# loopx 0.2.9

## Summary

`0.2.9` makes loopx repo specs and curated memory visible to planning and runtime agent context, without requiring `loopx init` or a mandatory specs index.

## Changed

- Added repo specs and memory reading rules to `clarify`, `spec`, and `plan-to-exec`.
- Added runtime discovery for `docs/loopx/specs/` and `.loopx/memory/` artifacts.
- Included relevant specs and memory in plan source context and build/review context manifests.
- Added opt-in `--add-agent-guidance` install support for Codex `AGENTS.md` and Claude `CLAUDE.md`.
- Documented specs as binding long-lived repo context and memory as advisory curated context.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.9`.
