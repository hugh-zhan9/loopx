# loopx 0.8.8

- Retire the orchestration skills dissolved by the v0.8 docs-first pivot
  (`exec`, `subagent-exec`, `parallel-subagent-exec`, `review`,
  `final-review`, `fix-review`, `finish`). The pivot removed them from the
  repository but never listed them as retired, so installs created before
  0.8 kept the orphaned skills indefinitely. The installer now removes any
  loopx-owned copy of them on the next run.
- Delete the empty `skills/subagent-exec/` directory left behind by the
  same pivot.
