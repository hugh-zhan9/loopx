# loopx 0.3.8

`0.3.8` adds multi-plan execution and review gates so large specs can be split
into independently executable child plans while `finish` remains guarded by a
spec-level review.

## Changes

- Added a `finish-record --status done` runtime gate for matching multi-plan
  package sources under `docs/loopx/plans/YYYY-MM-DD-<feature-slug>/`.
- Added local multi-plan state validation under
  `.loopx/multi-plan/<feature-slug>/state.json`, including missing, invalid,
  incomplete, and ready-for-finish cases.
- Updated `plan-to-exec`, `subagent-exec`, `final-review`, `finish`,
  `clarify`, and `RESOLVER` skill contracts for child plan execution,
  plan-level final-review, spec-level final-review, and finish-only hard gates.
- Added workflow, governance, plugin shell, package dry-run, and CLI smoke
  coverage for the new multi-plan flow.
- Added dated design and plan artifacts for the multi-plan execution review
  scope.
