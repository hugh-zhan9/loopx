# loopx 0.8.6

- Add `prompt-lint` as a bundled read-only support skill for assessing whether
  an agent prompt defines executable and verifiable work.
- Score goal clarity, necessary context, boundaries and authority, success
  evidence, and signal quality using a blocker-first rubric based on OpenAI's
  outcome-focused prompting guidance.
- Distinguish facts the user must supply, details worth adding, and repository
  context the agent can discover through narrow safe inspection.
- Keep prompt linting inside the docs-first boundary: never execute the checked
  prompt, mutate files, or invent missing product and compatibility decisions.
