# loopx 0.5.1

`0.5.1` adds a trace-first GPT-5.6 agent evaluation harness for measuring
prompt and orchestration changes without weakening task quality.

## Changes

- Added 12 representative GPT-5.6 workflow cases covering agent topology,
  dispatch, stopping, review accuracy, resume, safety, evidence, and finish.
- Added an NDJSON trace schema for native agent, tool, wait, retry, replacement,
  review, token, latency, and outcome events.
- Added deterministic run summaries and matched baseline/candidate comparison.
- Made nested worker dispatch a hard failure and added executable budgets for
  total agents, peak active agents, waits, retries, replacements, false-positive
  findings, and duplicate findings.
- Added JSON and Markdown reports through `npm run eval:agent -- --trace ...`.
- Added a provider-neutral live adapter contract. Synthetic traces validate the
  scorer but cannot be used to claim real GPT-5.6 performance gains.
- Added a native Codex rollout normalizer that resolves a root thread and child
  sessions, preserves parent identities, and records real agent/tool/token data.
- Packaged the eval contracts and runner with the npm release.
- Bumped the npm package and Codex plugin manifest versions to `0.5.1`.
