# loopx 0.2.5

## Summary

`0.2.5` makes the CLI onboarding surface cleaner for first-time users while preserving full runtime detail behind JSON and advanced help.

## Changed

- Reduced default `loopx status` output to the current stage, blockers, missing artifacts, and next command.
- Added `loopx next <slug>` for a short next-step prompt with JSON support for automation.
- Moved finish runtime commands out of default help and into `loopx help advanced`.
- Updated English and Chinese README onboarding docs with the golden path, install write summary, and uninstall guidance.
- Kept archive compatibility and internal readiness fields available through JSON/runtime paths instead of human default output.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.5`.
