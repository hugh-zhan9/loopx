# loopx 0.5.0

`0.5.0` is a breaking pre-1.0 release that resets the bundled skill suite to
the v2 current contract. Running pre-v2 workflow state is unsupported and must
restart; no migration or compatibility layer is provided.

## Changes

- Made the top-level controller the only owner of agent lifecycle operations.
  Every dispatched implementer, reviewer, fixer, and final reviewer is a leaf
  worker and cannot create or wait for other agents.
- Added a bounded agent budget and outcome-based dispatch stop rule to prevent
  exploratory, duplicate, or recursive subagent growth.
- Reworked the implementer worker prompt around goal, success criteria,
  constraints, validation, output, and stop rules for GPT-5.6-style prompting.
- Added explicit clarify handoff decisions: `needs_spec`, `direct_to_plan`, and
  `blocked`, with schema-v2 routing and read-only rejection of older state.
- Extracted shared agent, review, evidence, diagnosis, planning, and recovery
  contracts so each invariant has one canonical owner.
- Hardened issue, debug, TDD, verification, worktree, API, architecture, CLI,
  Go, SQL, Kratos, readability, requirements, refactor, and minimization rules.
- Added a packaged semantic contract matrix covering all 27 bundled skills,
  including boundary, output, safety, integration, reference, version, and
  workflow-root line guards.
- Aligned the resolver, bilingual public docs, installer surface, runtime,
  tests, and npm package with the v2 contract.
- Fixed finish-state resolution when a dated plan package directory declares a
  different package feature slug.
- Bumped the npm package and Codex plugin manifest versions to `0.5.0`.
