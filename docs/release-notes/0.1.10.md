# loopx 0.1.10

`0.1.10` strengthens plan review artifacts and generated HTML reading views for human approval.

## Changed

- Block plan handoff when reviewer-facing plan artifacts are not Chinese-readable.
- Require Planner, Architect, and Critic evidence artifacts before build approval.
- Render richer HTML reading views with visual summaries, artifact structure previews, and a dedicated change design page.
- Include change proposal, spec delta, design, tasks, and vertical slices in generated HTML review pages.
- Keep legacy English plan artifacts blocked after migration instead of treating them as current approved plan output.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.10`.
