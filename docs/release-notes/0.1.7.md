# loopx 0.1.7

`0.1.7` strengthens PRD traceability across planning, build context, and review.

## Added

- Added `requirement-traceability.md` generation and source-requirement coverage gating during `plan`.
- Added source requirements and requirement traceability rows to build/review context manifests.
- Added plan status output for `source_requirements_status` and `requirement_traceability_path`.

## Changed

- Updated plan runtime prompts to treat the original source requirements/PRD as the source of truth.
- Updated plan and review skill guidance to compare against original source requirements, not only the generated plan package.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.7`.
