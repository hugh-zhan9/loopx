# loopx 0.1.0

## Summary

`0.1.0` is the first loopx release candidate that pivots the repo away from `codex-helper` into a skill-first loopx product.

This release delivers:

- renamed loopx runtime/docs/package surface
- bundled loopx skills:
  - `clarify`
  - `plan`
  - `build`
  - `review`
  - `autopilot`
- npm/global install bootstrap
- plugin shell under `plugins/loopx/`
- shared install/discovery core across npm and plugin
- merged `installationIdentity=loopx` with provenance-aware convergence
- no public `team` release surface

## Install

Intended npm install command:

```bash
npm install -g @ai-content-space/loopx
```

Plugin install surface:

- `plugins/loopx/.codex-plugin/plugin.json`

## Highlights

### Skill-first product surface

The primary user-facing product surface is now the loopx skill bundle rather than a CLI-first flow.

### Shared install/discovery core

Both npm and plugin shells route through the same shared install/discovery core.

### Single installation identity

When npm and plugin installs both occur, they converge on one `installationIdentity=loopx` with merged provenance rather than duplicating the visible skill set.

### Runtime namespace

User-facing runtime state now lives under `.loopx/`.

### No public team lane

`team` has been removed from the current public release contract.
