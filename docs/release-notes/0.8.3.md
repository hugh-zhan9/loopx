# loopx 0.8.3

- Add the `maintain-project-docs` bundled support skill for repositories whose
  agents are being misled by stale, conflicting, or duplicated documentation.
- Keep current cross-cutting decisions in repository guidance and at most one
  stable current document per complex module; preserve runbooks, executable
  configuration, and product inputs in their distinct roles.
- Archive superseded plans, proposals, reviews, snapshots, and memory instead
  of leaving them on the active decision surface.
- Exclude archived material from default retrieval and prefer reversible index
  cleanup over permanent history deletion.
- Keep the skill outside the three canonical workflow intents: it maintains
  documentation authority but does not decide product intent, generate a
  reverse specification, or own execution.
