# loopx 0.2.10

## Summary

`0.2.10` expands the governed bundled support-skill surface with document, API, architecture, SQL/database, and CLI discipline lenses while keeping the core loopx workflow unchanged.

## Changed

- Added `requirement-analyzer` as a governed support skill for PRD, requirement, feature brief, ambiguity, gap, feasibility, and readiness analysis.
- Added `api-designer`, `architecture-designer`, `sql-style`, and `cli-developer` as support lenses for API, architecture, database, and CLI work.
- Mirrored the new bundled skills into the loopx plugin skill set.
- Added `sql-style` as the shared SQL/database lens and linked it from `kratos` while preserving Kratos-specific MySQL comment rules.
- Updated the resolver, README files, and v1 design document to describe support skills as lenses, not workflow states.
- Added governance coverage for the expanded support-lens skill surface.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.10`.
