# loopx 0.3.3

`0.3.3` reduces confusion between loopx finish summaries and assistant final
channels.

## Changes

- Renamed the finish skill's `Final Response Contract` wording to
  `Completion Summary Contract`.
- Clarified that `exec` and `subagent-exec` should only start `finish` after
  `final-review` is clean or blocking feedback has been handled and rechecked.
- Added governance coverage so finish wording does not regress into
  final-channel terminology.
