# loopx 0.2.7

## Summary

`0.2.7` keeps the default CLI surface focused on skill-first user guidance while preserving runtime compatibility in advanced and JSON paths.

## Changed

- Moved `loopx review <slug>` out of default help and public docs into `loopx help advanced`.
- Hid runtime `next cli` fallbacks from human `loopx clarify`, `loopx status`, and `loopx next` output.
- Preserved CLI fallback commands in JSON/machine-oriented next-step payloads.
- Updated initialized workspace README text to show the skill-first flow and default user commands.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.7`.
