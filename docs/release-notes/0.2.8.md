# loopx 0.2.8

## Summary

`0.2.8` renames the bundled implementation-planning skill from `plan` to `plan-to-exec` while keeping the runtime stage model and `loopx plan` CLI command unchanged.

## Changed

- Renamed the canonical bundled skill directory and frontmatter name from `plan` to `plan-to-exec`.
- Updated skill handoff prompts, installer output, plugin mirrors, and public docs to use `$plan-to-exec`.
- Kept workflow runtime stages, review rollback targets, and the `loopx plan` CLI surface on the existing `plan` terminology.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.2.8`.
