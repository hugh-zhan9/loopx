# loopx 0.4.1

`0.4.1` is a patch release for the multi-plan package finish gate.

## Changes

- Fixed multi-plan finish detection so package directory sources, with or
  without a trailing slash, use the same schema v2 finish gate as
  `00-overview.md` and numbered child plan sources.
- Added workflow tests for package directory sources with missing multi-plan
  state and clean spec-level review state.
- Bumped the npm package and Codex plugin manifest versions to `0.4.1`.
