# loopx 0.1.5

`0.1.5` strengthens project-local context preservation and repository governance while keeping loopx's full closed workflow unchanged.

## Added

- Added init-time project discovery for existing AI rule files, existing spec sources, and common verification commands.
- Added `.loopx/config.json` context manifest rows for build and review so downstream stages can use project-native commands and preserve local sources of truth.
- Added public documentation governance checks for Markdown structure, README command alignment, and current-version release notes.

## Changed

- Documented `.loopx/config.json` as supporting context, not a lightweight workflow profile or replacement for loopx artifacts.
- Updated build and review skill contracts to consume `.loopx/config.json` as supporting context for project rules, spec sources, and verification commands.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.5`.
