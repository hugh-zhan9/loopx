# loopx 0.3.4

`0.3.4` makes loopx's public documentation and skill governance match its
skill-first product shape.

## Changes

- Reworked the English and Chinese READMEs around using loopx as an installed
  agent skill suite.
- Moved detailed CLI and installation reference material into dedicated
  English and Chinese CLI docs.
- Added `npm run sync-plugin-skills` so plugin skill mirrors are generated from
  canonical bundled skills under `skills/`.
- Decoupled skill `metadata.version` from the npm package version. Package and
  plugin manifest versions now follow releases; individual skill versions move
  only when that skill's content or behavior contract changes.
- Updated `go-style` with numeric precision guidance for exact business
  quantities and bumped only that skill to `0.3.4`.
