# loopx 0.3.0

## Summary

`0.3.0` hardens the governed workflow skill surface by expanding requirement analysis references, aligning `exec`/`review`/`final-review` gate semantics with their reviewer prompts, and keeping the bundled plugin mirror in lockstep.

## Changed

- Expanded `requirement-analyzer` with additional readiness, behavioral-model, traceability, and quality-attribute reference material in both canonical and plugin-mirrored skill sets.
- Strengthened `review` with a degraded intent-check path for ad-hoc work and aligned the Stage 2 code-quality prompt with the staged review model.
- Strengthened `exec` with explicit periodic review triggers, persisted checkpoint files, and stricter task completion rules around review outcomes.
- Strengthened `final-review` with requirements coverage, runtime validation, regression assessment, and reviewer-prompt alignment for whole-feature gates.
- Added governance coverage to keep `exec`, `review`, `final-review`, and their supporting prompts structurally aligned.
- Bumped package, plugin manifest, and bundled skill metadata versions to `0.3.0`.
