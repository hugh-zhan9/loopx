# loopx 0.1.4

## Summary

`0.1.4` strengthens the bundled skill governance surface while keeping the public workflow unchanged:

- `clarify -> plan -> build -> review -> done -> archive`
- eleven bundled Codex skills
- npm and plugin install convergence under `installationIdentity=loopx`

## Highlights

### Skill resolver

Added `skills/RESOLVER.md` as the central human-readable routing map for bundled skills. It documents workflow skills, support skills, and disambiguation rules.

### Deterministic skill governance

Added `scripts/verify-skills.mjs` and wired it into `npm test`.

The verifier checks:

- bundled skill frontmatter is triggerable and bounded
- `metadata.version` matches `package.json`
- plugin skill mirrors match canonical skills
- `skills/RESOLVER.md` covers every bundled skill
- local skill references exist
- plugin manifest version matches package version
- the verifier itself is included in the npm package

### Plugin version alignment

Aligned `plugins/loopx/.codex-plugin/plugin.json` with package version `0.1.4`.

## Verification Snapshot

Validated before handoff:

- `node scripts/verify-skills.mjs`
- `npm test`
