# loopx 0.1.9

`0.1.9` aligns review approval handoff with archive's ability to consume pending completion.

## Changed

- Updated approved review next-step guidance to use `$archive <slug>` as the normal Codex-facing handoff.
- Updated review runtime messages and workflow hook next-action output so archive consumes pending `review -> done` completion before syncing specs.
- Kept explicit `loopx approve <slug> --from review --to done` guidance only as a CLI/runtime debugging equivalent.
- Bumped package, plugin, and bundled skill metadata versions to `0.1.9`.
