# loopx 0.4.2

`0.4.2` is a patch release for final-review evidence hardening.

## Changes

- Strengthened `final-review` so covered requirements must be supported by
  evidence from the same claimed surface.
- Added explicit handling for UI/product, CLI/API, persistence, workflow, and
  parity claims so lower-level model, unit, smoke, or launch evidence cannot
  produce a green finish by itself.
- Added claim evidence audit sections to the English and Chinese final-review
  report templates.
- Updated governance tests to preserve the new final-review evidence-surface
  contract.
- Bumped the npm package and Codex plugin manifest versions to `0.4.2`.
